# Futchibolee# ⚽ Futchibolee

**Futchibolee** es un juego arcade casual de fútbol con un toque surrealista, donde la física caótica y las mecánicas simples se combinan para ofrecer diversión inmediata y partidas impredecibles. Creado en Unity, este juego está disponible para navegador en [itch.io](https://sergioc2021.itch.io/futchibolee).

![Gameplay Screenshot](https://img.itch.zone/aW1hZ2UvMzUyMzYxOS8yMDk5MzU0MC5wbmc=/original/P1ndYG.png)

## 🎮 Cómo jugar

- Usa **W** para mover a tus jugadores.
- El objetivo es simple: ¡mete goles y evita que te anoten!

## 🧠 Mecánicas destacadas

- Movimiento por física: los personajes rebotan y se deslizan con una física exagerada que hace cada partido único.
- Estilo visual caricaturesco: con personajes y entornos coloridos que recuerdan a juegos de los 2000.
- Rondas rápidas: ideal para sesiones cortas y risas aseguradas.

## 🛠️ Tecnologías

- **Motor**: Unity
- **Lenguaje**: C#
- **Plataforma**: WebGL (jugable en navegador)
